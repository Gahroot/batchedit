# BatchEdit

Electron desktop app that generates combinatorial video permutations from ad creative clips organized into Hook, Meat, and CTA buckets, then batch renders them with FFmpeg and optional Whisper-powered captions.

## Install

```bash
npm install
```

## Run in development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```
